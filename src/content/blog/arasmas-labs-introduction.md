If you're reading this I can say confidently that we've finally launched the Arasmas Labs website. It took about 5 weeks from the start of using AI to get to here with no experience whatsoever in coding.

All I can really say is I've learned a lot. And I'll likely continue learning as this journey moves forward. So far the website looks as polished and clean as I can make it with the provided direction I gave to GPT. I did a lot of planning and lot of debugging and learning how things worked. But I took my time with it and this is the result.

So why Arasmas Labs?

Well mainly for documentation's sake. I don't want to just build. I want to document what I build so that ideas can be improved upon. Or maybe I can potentially inspire someone. 

The over-arching "lab" doesn't necessarily exist yet, but in concept and that's okay for right now. For now, this site is a functional space for what could one day become something much bigger. Maybe. If I push it that far.

But Arasmas Labs is my pet project. I want to see what I can do with it. I want to see how it'll help me develop my skills. And most importantly, I want to see how it can help me bring my ideas to life 

At this point, all we can do is Forge Forward. There is nowhere else to go, but up.

So in the spirit of keeping this short and concise

Welcome to Arasmas Labs. I hope you enjoy your stay. 

And if you have any ideas or recommendations, feel free to access the contact page.
